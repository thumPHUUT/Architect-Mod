# Architect-Mod
This is a custom character mod for Risk of Rain 2 made using the HenryTutorial community template. Do note that this build only works on Devotion update version of the game. The artstation for this project can be [found here](https://www.artstation.com/artwork/8B5gEq)

If you wish to try this for yourself, download the mod using a mod manager (preferably r2modman) and import as a local mod. This is not uploaded publically on thunderstore due to instability caused by recent codebase changes. 
For those who dont know, this issue was caused during the transition of the RoR2 franchise to Gearbox, who erroniously updated the entire game codebase, (initially) causing major game-breaking bugs and mod incompatability.

To reiterate, this mod must be played on Devotion update versions of the game. Detailed tutorials on downpatching to this update can be found here: 
    manually (this is sometimes preffered): [https://bage.cab/ror2/downpatch](https://gist.github.com/SSM240/c18b69751ecd5d29f3fec608f075386e)
    using downpatcher: [video tutorial](https://www.youtube.com/watch?v=isxPWzuh97U)
